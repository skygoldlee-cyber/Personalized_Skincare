🎯 맞춤학습 PRO

내 학습 기록(퀴즈 정답률·오답 원인·드릴 오판·모의고사 성적)을 모아 지금 약한 곳과 먼저 할 일을 보여주는 개인화 분석 화면입니다. 각 카드의 버튼을 누르면 해당 학습 화면으로 바로 이동합니다.

  • 🧩 오답 패턴 분석 — 최근 7일의 틀린 이유(암기 부족·개념 오해·계산 실수)를 집계해 어떤 공부법이 필요한지 알려줍니다.
  • 🎯 취약 진술 추적 — O/X·복수정답형 드릴에서 반복해서 오판한 진술을 자동 수집하고, 복습 시기(SM-2)가 되면 알려줍니다.
  • 📅 학습 리듬 — 오늘 목표 달성률·주간 학습일·시험 D-day를 추적해 꾸준한 학습 습관을 돕습니다.
  • 📊 과목별 상태·히트맵 — 과목별 진도와 정답률을 색으로 비교해 취약 과목을 한눈에 찾습니다.
  • 📈 성적 추이·합격 예측 — 모의고사 이력으로 점수 추세·과락 위험·예상 점수를 진단합니다.

💡 기록이 쌓일수록 정확해집니다 — 퀴즈·오답 복습·드릴·모의고사를 진행하면 분포·히트맵·예측이 자동으로 채워집니다.
