## Ch01 원료의 종류와 특성

### ⭐⭐⭐ 최빈출

- **HLB 0~20**: 높을수록 친수성. 3~6 W/O 유화제 / 8~14 O/W 유화제 / 15~18 가용화제
- **계면활성제 4종**: 음이온(세정력 최고) / 양이온(살균·헤어케어) / 양쪽성(영유아용 저자극) / 비이온(기초화장품 유화)
- **제조 3대 기술**: 가용화(스킨토너·미스트) / 유화(크림·로션) / 분산(파운데이션·마스카라)
- **보습 4종**: 밀폐제(바세린) · 연화제(오일) · 습윤제(글리세린) · 장벽대체제(세라마이드)
- **보존제 한도**: 페녹시에탄올 1.0% / 벤질알코올 1.0% / 파라벤 단일 0.4%·혼합 0.8% / 살리실릭애씨드 0.5%

### ⭐⭐ 빈출

- **산화방지제 vs 금속이온봉쇄제**: 산화방지제=자체 산화(BHT·토코페롤), 봉쇄제=금속이온 제거(EDTA)
- **부향률**: 향수 15~20% / 오드퍼퓸 10~15% / 오드뚜왈렛 5~10% / 오드코롱 3~5%
- **법정색소 5단계**: 타르색소 → 산화염료 → 유기안료 → 무기안료 → 천연색소

→ 상세: [Ch01 원료 핵심암기](2과목_Ch01_원료_핵심암기.md)

## Ch02 제조관리

### ⭐⭐⭐ 최빈출

- **CGMP 4대 기준서**: 제품표준서 · 제조관리기준서 · 위생관리기준서 · 품질관리기준서
- **제품 단계**: 원료 → 반제품 → 벌크 → 완제품 (단계별 품질 기준 상이)
- **CGMP 3대 요소**: 과오 최소화 · 미생물오염 방지 · 품질관리체계
- **CGMP 5장**: 총칭 → 인적자원 → 제조 → 품질관리 → 판정 및 감독

### ⭐⭐ 빈출

- **제조공정 흐름**: 원료 → 배합 → 제조 → 충진·포장 → 출하
- **맞춤형화장품**: 내용물+내용물/원료 혼합 또는 소분, 고형비누 단순소분 제외

## Ch03 기능과 품질·사용제한 원료

### ⭐⭐⭐ 최빈출

- **별표 1 vs 별표 2**: 별표 1 = 사용금지 / 별표 2 = 사용제한(기준·시험방법 정해짐)
- **영유아 3세 이하 금지**: 살리실릭애씨드 · IPBC · 부틸/프로필파라벤 (씻어내는 제품 제외)
- **알레르기 유발 성분 25종 표시 의무**: 씻어내는 0.01% 초과 / 남기는 0.001% 초과
- **자외선차단제 한도**: 티타늄디옥사이드·징크옥사이드 25% / 벤조페논-3 2.4%(얼굴·손·입술 5%)
- **AHA**: 10% 초과 시 주의사항 표시 · pH 3.5 미만 시 표시

### ⭐⭐ 빈출

- **천연·유기농**: 용기·포장에 PVC·PSF 사용 불가
- **트리클로산**: 0.3% (기능성 유효성분 예외, 씻어내는 제품)
- **치오글리콜릭애씨드**: 퍼머 제1제 환원제 11% / 제모용 3.0~4.5%(pH 7.0~12.7)
- **IPBC**: 0.02%(씻어내는) / 0.01%(남기는), 목욕·샤워젤·샴푸 제외

→ 상세: [Ch03 사용제한원료 핵심암기](2과목_Ch03_사용제한원료_핵심암기.md)

## Ch04 화장품 관리

### ⭐⭐⭐ 최빈출

- **기능성화장품 심사**: 심사신청 → 심사 → 결과 통보 / 보고서 제출 시 15일 처리
- **기능성 효능별 성분 한도**: 미백 나이아신아마이드·알부틴 2.0~5.0% / 주름 아데노신 0.04%·레티놀 2,500IU/g
- **SPF/PA 표시**: SPF 50 이상 = "50+" / PA+ (2~4) · PA++ (4~8) · PA+++ (8~16) · PA++++ (16~)

### ⭐⭐ 빈출

- **취급·보관·사용상 주의사항**: 원료별 표시 문구, 영유아용 성분은 원료별로 따로 확인
- **제품 단계별 보관 조건 상이**

## Ch05 위해사례 판단 및 보고

### ⭐⭐⭐ 최빈출

- **위해성 평가 4단계**: 위해요소 확인 → 위해요소 평가 → 위해 특성화 → 위해 특성 서술
- **회수계획서**: 회수 대상임을 안 날부터 **5일 이내** 지방식약청장 제출
- **회수 기간**: 가등급 **15일** / 나·다등급 **30일** 이내
- **안전성 정보 신속보고**: **15일 이내**

### ⭐⭐ 빈출

- **위해성 등급**: 위해 정도에 따라 등급 분류, 등급별 회수 조치 차등
- **회수 보고**: 위해화장품 회수 시 **즉시** 보고

## ⚠️ 혼동 함정표

| 함정 | 정답 |
| --- | --- |
| 음이온성이 세정력 최고니까 헤어에도? | 헤어케어는 **양이온성** |
| 미백 표시는 일반 화장품도 가능? | **기능성화장품 심사 필수** |
| 천연원료면 한도 없음? | 보존제·자외선차단제는 **한도 있음** |
| 가등급 회수 30일? | 가등급 **15일** / 나·다만 30일 |
| 3세 이하 금지 성분은 하나로? | 원료별로 **따로 확인** |
| HLB 8~18이 전부 O/W? | 8~14 유화제 / **15~18은 가용화제** |
| 별표 1이 사용제한? | 별표 1 = **사용금지**, 별표 2 = 사용제한 |
| 파라벤 0.8%는 단일 한도? | 단일 **0.4%** / 혼합 **0.8%** |
