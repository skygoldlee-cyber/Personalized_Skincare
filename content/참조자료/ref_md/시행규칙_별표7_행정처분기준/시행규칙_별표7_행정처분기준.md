# 시행규칙 별표 7 — 행정처분의 기준 (제29조제1항 관련)

> 화장품법 시행규칙 [별표 7] <개정 2025. 2. 7.>

---

## 1. 일반기준

| 구분 | 내용 |
| --- | --- |
| 가. 위반행위 2개 이상 | 무거운 처분 기준 적용. 다만, 업무정지가 2개 이상이면 가장 무거운 처분 + 나머지의 ½ 합산 (최대 12개월) |
| 나. 업무정지 + 품목업무정지 | 업무정지 ≥ 품목업무정지 → 업무정지 처분; 업무정지 < 품목업무정지 → 병과 |
| 다. 위반 횟수 적용 | 최근 1년간(제2호 머·바·사·아·자·차·카·타 항목은 최근 2년간) 같은 위반행위로 처분받은 경우 적용 |
| 라. 가중 부과 | 가중 처분 차수 = 위반 행위 전 부과 처분 차수의 다음 차수 |
| 마. 진행 중 반복 위반 | 진행 중인 처분 기준의 ½ 추가 (최대 12개월) |
| 바. 과징금 제외 | 같은 위반행위 3차 이상 → 과징금 부과 대상 제외 |
| 사. 시설 전무 | 등록한 소재지에 시설이 전혀 없으면 등록 취소 |
| 아. 수입대행책임판매업자 | "판매금지"→"수입대행금지", "판매업무정지"→"수입대행업무정지"로 본다 |
| 자. 감경·면제 | ① ½ 감경 또는 면제: 공익상 필요, 기소유예/선고유예, 무단광고 ② ½ 감경: 함량 미달(보관상태 불량), 비병원성세균 오염(보관상태 불량) |
