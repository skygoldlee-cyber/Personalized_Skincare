# 4과목 핵심요약 — 맞춤형화장품의 이해 (출제 40%)

> **시험 비중 40%** — 가장 큰 배점. 조제관리사 제도·안전성/안정성시험·피부모발 생리·실무 전 과정이 최빈출.
> 법령·고시 수치는 개정될 수 있으니 최신 공식 기준과 함께 확인.

## Ch01 맞춤형화장품 개요

### ⭐⭐⭐ 최빈출

- **맞춤형화장품 2유형**: 혼합형(내용물+내용물/고시원료) / 소분형 — **고형비누 단순소분 제외**
- **판매업**: 지방식약청장 **신고** (등록 아님) + 조제관리사 필수 배치
- **결격사유**: 판매업 등록취소·폐쇄 후 **1년** 미경과 / 조제관리사 자격취소 후 **3년** 미경과
- **자격시험**: 매년 1회 이상 / **90일 전 공고** / 전 과목 **60%**·매 과목 **40%** 이상 / 부정행위 응시 제한 **3년**
- **변경신고**: **30일 이내** (처리 10일 / 조제관리사 7일)

### ⭐⭐ 빈출

- **교육**: 최초 **6개월 이내** / 보수 **매년 1회** / **4~8시간**
- **안전성시험 9종**: 단회독성 · 1차피부자극 · 연속피부자극 · 안점막 · 감작성 · 광독성 · 광감작성 · 인체첩포 · 유전독성
- **유효성**: 효력시험(비임상) + 인체적용시험(**5년 이상 경력자 지도·감독**, 헬싱키선언, 서면 동의서) + SPF/PA
- **안정성시험 4종**: 장기보존 / 가속(+15℃ 이상) / 가혹(-15~45℃) / 개봉 후 — **공통: 3로트 이상·6개월 이상**

## Ch02 피부 및 모발의 생리구조

### ⭐⭐⭐ 최빈출

- **표피 5층**(안→밖): 기저층 → 유극층 → 과립층 → 투명층 → 각질층
- **표피 4대 세포**: 각질형성세포 · 멜라노사이트 · 랑게르한스세포 · 메르켈세포
- **각질층 구성**: 케라틴 58% · NMF 31% · 지질 11% / 각화주기 **28±3일**
- **NMF 구성**: 아미노산 40% · PCA 12% · 젖산염 12% · 요소 7%
- **모발 성장주기**: 성장기 **3~6년**(전체 80~90%) → 퇴행기 **3주** → 휴지기 **3~4개월**
- **모간 3층**: 모표피(5~15층) · 모피질 · 모수질

### ⭐⭐ 빈출

- **진피**: 유두층+망상층, 콜라겐 90% · 엘라스틴 1.5~4.7% (콜라겐=피부 건조 중량 75%·아미노산 1,000개)
- **세라마이드**: 세포간지질 50% 이상
- **멜라노사이트**: 표피 10~20%, 각질형성세포와 4:1~10:1
- **자외선 3종**: UVA(색소침착) · UVB(홍반·DNA 손상) · UVC(오존층 차단)
- **모발 성장**: 1일 0.3~0.5mm / 하루 50~100가닥 탈락
- **피부 분석**: 문진·견진·촉진·기기 / 피츠패트릭 6형

## Ch03 관능평가 방법과 절차

### ⭐⭐⭐ 최빈출

- **관능평가 4단계**: 표준품 선정 → 검체 채취·기준 마련 → 시험 → 적합 판정·기록
- **오감 활용**: 시(외관·색) · 후(향) · 미(맛) · 촉(점도·감촉) · 청(소리) — **전문가 패널 평가 + 통계 처리 필수**
- **제형별 평가**: 액상(투명도·점도) / 크림(크림성·발림성) / 분말(입도·색 균일성)

### ⭐⭐ 빈출

- **물리적·광학적 요소** 평가와 사용시험 구분

## Ch04 제품 상담

### ⭐⭐⭐ 최빈출

- **부작용 8종**: 접촉성피부염 · 광과민반응 · 색소침착 · 모낭염 · 가역적 탈모 · 홍반 · 가려움 · 건조
- **부작용 보고**: 식약처장에게 **즉시** 보고 의무
- **원료 관리**: 별표 1(배합금지) · 별표 2(사용제한) — 기능성화장품 심사 받은 고시 원료는 제외

### ⭐⭐ 빈출

- **상담 기법**: 고객 고민 파악 → 피부 분석 → 제품 추천

## Ch05 제품 안내

### ⭐⭐⭐ 최빈출

- **포장 기재사항**: 제품명 · 전성분 · 중량 · 사용기한 · 제조번호 · 가격 — **5포인트 이상** 글자
- **실증**: 광고 전 **15일 이내** 효력시험 실증 자료 보관 의무
- **금지 표현**: 의학적 효능 · 허위·과장 광고 · 질병 치료 목적 표현 금지

### ⭐⭐ 빈출

- 의약품 오인 표현 금지, 기능성 오인 주의

## Ch06 혼합 및 소분

### ⭐⭐⭐ 최빈출

- **혼합 원료**: **고시원료만** 혼합 가능 (아무 원료나 불가)
- **혼합·소분 전**: 내용물·원료 **품질성적서 확인** → 사용기한 확인 → 손 소독 → 용기 오염 확인
- **판매내역서** 작성 필수
- **제형 안정성**: 분리(유화 파괴) · 변색(산화) · 변취(향료 변질) — 안정성시험 4종으로 판정

### ⭐⭐ 빈출

- **원료 분류**: 수성(물 용해) · 유성(수분 증발 억제) · 계면활성제(유·수 혼합) · 고분자(점도 조절)

## Ch07 충진 및 포장

### ⭐⭐⭐ 최빈출

- **충진기 6종**: 피스톤(대용량 액상) · 파우치(샘플·일회용) · 튜브(폼클렌징) · 스프레이 · 펌프 · 자동
- **포장 공간 비율**: 세정용 **15% 이하·2차 이내** / 기타 **10% 이하** / 종합 **25% 이하**
- **라벨링**: 소분 시 새 용기에 기재사항 스티커 / 혼합 시 기존 라벨 제거 후 새 라벨 또는 오버라벨링

### ⭐⭐ 빈출

- **납 한도**: 분말 50 / 기타 20㎍/g / 미생물(영유아·눈화장) 500 CFU/g 이하

| 함정 | 정답 |
| --- | --- |
| 고형비누도 소분형? | 고형비누 **단순소분은 제외** |

| 성장기가 가장 짧음? | 성장기 **3~6년**으로 가장 김 |
| 관능평가는 주관적이니 생략? | **전문가 패널 평가 필수** |
| 혼합은 아무 원료나? | **고시원료만** 혼합 가능 |
| 결격사유 둘 다 1년? | 판매업 **1년** / 조제관리사 **3년** |
| 표피 층 순서? | 기저→유극→과립→투명→각질 (안→밖) |
| 부작용은 나중에 보고? | 식약처장에 **즉시** 보고 |
| 세정용 포장공간 10%? | 세정용 **15%** / 기타 10% |
