# 3과목 핵심요약 — 유통화장품 안전관리 (출제 25%)

> **시험 비중 25%** — 청정도·소독제·중금속·미생물·포장재 숫자가 최빈출.
> 법령·고시 수치는 개정될 수 있으니 최신 공식 기준과 함께 확인.

## 🎯 1분 요약표

| 축 | 핵심 |
| --- | --- |
| 위해 회수 | 위해성 평가 → 회수계획 → 회수 → 결과보고 (가 15일 / 나·다 30일) |
| 청정도 | 1등급(무균, 20회/hr) ~ 4등급(일반) |
| 필터 순서 | P/F → M/F → H/F (HEPA 0.3㎛ 99.97%) |
| 낙하균 | Koch법, 고청정 시설 30분 이상 노출 |
| 손 위생 | 세정 15초 이상, 소독 4종, 일회용 장갑 시 예외 |
| 저울 | 영점·수평 매일 / 정기점검 1개월 1회 |
| 입고 라벨 | 백색(대기) → 황색(시험 중) → 청색(적합) / 적색(부적합) |

| 포장 | 1차=내용물 직접 접촉 / 2차=보호·표시 |

## Ch01 작업장 위생관리

### ⭐⭐⭐ 최빈출

- **청정도 4등급**: 1등급(무균실, H/E) → 4등급(일반, P/F) — 등급별 작업실·필터·환기 기준 상이
- **공기순환**: 1등급 20회/hr 이상 / 2등급 10회/hr 이상
- **필터**: P/F → M/F → H/F, HEPA 0.3㎛ 99.97% 제거, 교체주기 필수
- **낙하균/부유균**: 1등급 낙하 10개/hr·부유 20개/㎥ / 2등급 낙하 30개/hr·부유 200개/㎥
- **소독제 6종**: 에탄올·크레졸·차아염소산·페놀·벤잘코늄·글루콘산 / 물리적 3종(건열·습열·자외선)

### ⭐⭐ 빈출

- **시설용 소독**: 70% 에탄올 · 50ppm 차아염소산나트륨 · 3% 크레졸수·페놀수
- **소독 전 사멸률**: 99.9% 이상
- **낙하균 Koch법**: 배지 → 노출 → 배양 → 집락수 (고청정 시설 30분 이상 노출)

## Ch02 작업자 위생관리

### ⭐⭐⭐ 최빈출

- **손 세정**: 15초 이상 → 소독, 혼합·소분 전 원칙 (**일회용 장갑 착용 시 예외**)
- **손 소독제 4종**: 알코올 70~80% · 클로르헥시딘 0.5~4.0% · 헥사클로로펜 3.0% · 아이오도퍼 0.5~10%
- **질병자 격리**: 피부 외상·질병 직원은 의사 소견 전까지 화장품 접촉 금지

### ⭐⭐ 빈출

- **작업복**: 작업소·보관소 내 규정된 작업복, 음식물 반입 금지
- **CGMP 3대 요소**: 과오 최소화 · 미생물오염 방지 · 품질관리체계

## Ch03 설비 및 기구관리

### ⭐⭐⭐ 최빈출

- **저울**: 영점·수평 **매일** 확인 / 정기점검 **1개월 1회** / 편심오차 ±0.1%
- **세척 판정 3종**: 육안 확인 · 린스 정량법 · 세균시험
- **설비 재질**: **316 스테인리스**가 304보다 부식에 강해 탱크·필터·파이프에 선호
- **세척 순서**: 물 우선 → 최소 세제 → 판정 → 건조·밀폐

### ⭐⭐ 빈출

- **면봉 멸균**: 121℃ / 20분, 시험 면적 24~30㎠
- **세척제 pH 구간**: 0.2~5.5 / 5.5~8.5 / 8.5~12.5 / 12.5~14

## Ch04 내용물 및 원료관리

### ⭐⭐⭐ 최빈출

- **입고 라벨 4색**: 백색(판정 대기) → 황색(시험 중) → 청색(적합) / 적색(부적합→반품)
- **중금속**: 납 20(분말 50) · 비소 10 · 안티몬 10 · 카드뮴 5 · 수은 1 ㎍/g 이하
- **미생물**: 일반 1,000 / 영유아·눈화장 500 / 물휴지 세균·진균 각 100 CFU/g 이하
- **검출 금지 병원균**: 대장균 · 녹농균 · 황색포도상구균

### ⭐⭐ 빈출

- **유해물질**: 디옥산 100㎍/g · 메탄올 0.2%(물휴지 0.002%) · 포름알데하이드 2,000㎍/g(물휴지 20㎍/g)
- **니켈**: 눈화장 35 · 색조 30 · 기타 10 ㎍/g / 프탈레이트류 합계 100㎍/g
- **내용량**: 평균 97% 이상 / 액상 pH 3.0~9.0 / 화장비누 유리알칼리 0.1% 이하
- **퍼머 제1제**: 중금속 20 · 비소 5 · 철 2 ㎍/g / 제2제 pH 4.0~10.5(브롬산)·2.5~4.5(과산화수소)

## Ch05 포장재 관리

### ⭐⭐⭐ 최빈출

- **1차 vs 2차 포장**: 1차 = 내용물 **직접 접촉** / 2차 = 외부 보호·표시용
- **용기 4종**: 플라스틱 · 유리 · 금속 · 적층
- **안전용기 의무**: 탄화수소 10% · 메틸살리실레이트 5% 이상 함유 제품
- **식품용기 기준 준수 필수**

### ⭐⭐ 빈출

- **포장 시험**: 밀봉성 · 낙하 · 내용물 이행 시험
- **인체 세포 배양액**: 청정등급 1B · 기록 보존 3년

## ⚠️ 혼동 함정표

| 함정 | 정답 |
| --- | --- |
| 1등급이면 필터 안 바꿔도? | **HEPA 교체주기 필수** |
| 손 세정 10초면 충분? | **15초 이상** |
| 저울 영점은 가끔만? | **매일** 영점·수평, 정기점검 1개월 |
| 영유아용 미생물 기준 같음? | **500 CFU/g**로 더 엄격 (일반 1,000) |
| 장갑 끼면 손 소독 생략? | **일회용 장갑 착용 시에만 예외** |
| 304가 316보다 내식성? | **316이 더 강함** |
| 라벨 황색이 적합? | 황색=시험 중 / **청색=적합** |
| 2차 포장이 내용물 접촉? | **1차 포장**이 직접 접촉 |
| 가등급 회수 즉시? | **15일 이내** (나·다는 30일) |
| 포장재 아무거나? | **식품용기 기준 준수 필수** |
