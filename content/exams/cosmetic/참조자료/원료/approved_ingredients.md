# 화장품 원료 데이터베이스

화장품 조제사/기능사 자격증 시험 대비를 위한 통합 원료 데이터베이스입니다.

---

## 데이터 구조

아래 12개 필드는 **논리적 마스터 스키마(전체 필드의 합집합)** 입니다. 실제 표는 섹션 성격에 따라 이 중 **필요한 일부만** 사용하며, 12개 필드를 모두 가진 표는 없습니다(의도된 설계).

| 필드 | 설명 | 표현 방식 |
|------|------|-----------|
| 원료명 | 성분의 한국어 이름 (일부 표는 `성분명`으로 표기) | 컬럼 |
| 카테고리 | 성분의 기능적 분류 (보습제, 오일, 계면활성제, 보존제, 산화방지제, 자외선 차단제, 염모제, 색소, 향료, 기능성 성분 등) | 컬럼 |
| 베이스 | 성분의 용해성 (수상층, 유상층, 양쪽) | 컬럼 |
| 특성 및 설명 | 성분의 주요 기능과 특성 | 컬럼 |
| 일반 함량 범위 | 일반적으로 사용되는 함량 범위 (%) | 컬럼 |
| 최대 함량 | 법적으로 허용된 최대 함량 (%). 표에 따라 `사용한도`, `사용할 때 농도상한(%)`으로도 표기 | 컬럼 |
| 증상 효과 | 해당 성분이 효과가 있는 피부 증상 (미백, 주름, 탄력, 보습, 트러블, 홍조, 모공, 피부결, 지성, 건성, 민감성 등) | 컬럼 (전 표 공통) |
| **사용 금지 여부** | 사용 금지 원료(별표1)인지 여부 | **컬럼 아님 — `banned_ingredients.md` 수록 여부로 표현** |
| **알레르기 유발 여부** | 알레르기 유발 성분 25종 포함 여부 | **컬럼 아님 — `approved_ingredients.md`의 "알레르기 유발 성분 25종" 섹션 수록 여부로 표현** |
| 시험 출제 빈도 | 시험 출제 빈도 (고빈도, 중빈도, 저빈도) | 컬럼 |
| 고득점 TIP | 시험에서 고득점을 위한 중요 팁 | 컬럼 |
| 비고 | 추가 참고 사항 (일부 표는 `설명`, `예외 조건`으로 표기) | 컬럼 |

> **파생 필드 주의:** `사용 금지 여부`와 `알레르기 유발 여부`는 표의 컬럼이 아니라 **성분이 어느 파일·섹션에 있는지**로 판별합니다. 프로그램(파서)도 컬럼이 아닌 파일/섹션 소속으로 이 두 값을 도출합니다.

## 참고: 시험 출제 빈도 기준

- **고빈도**: 시험에서 매우 자주 출제되는 성분, 반드시 암기 필요
- **중빈도**: 시험에서 종종 출제되는 성분, 이해 필요
- **저빈도**: 시험에서 가끔 출제되는 성분, 참고 사항
