## 2. 서비스 소개 (영상에 반영할 제품 이해)

Passmula는 **맞춤형화장품 조제관리사 국가시험**을 준비하는 수험생과,
합격 후 조제판매업소에서 실제 일하는 **조제관리사 실무자**를 동시에 지원하는
모바일 웹 앱(PWA)입니다.

**두 개의 루프가 하나의 플랫폼을 이룹니다:**

- **Pass Loop (시험 합격)**: 교재 리더, 기출 퀴즈, 플래시카드, SM-2 간격 반복,
  실전 모의고사, 오답 분석, 숫자 암기 훈련, 오디오북
- **Practice Loop (실무)**: Formula OS — 배합 계산기, 원료 DB(1,376종) 규정 검증,
  고객 카드·상담 이력, 조제 기록(배치), 원료 입고 장부, 사용 안내문 생성,
  법규 준수 체크리스트, 라벨·기록지 인쇄

**핵심 차별점**

1. **합격에서 실무까지 이어지는 유일한 플랫폼** — 일반 수험 앱은 합격 후 이탈,
   Passmula는 합격 후 조제 실무 도구로 전환되어 계속 사용
2. **설치 없이 바로 사용** — 별도 앱 다운로드 없이 브라우저 주소만으로 접속,
   홈 화면 추가 시 앱처럼 동작 (오프라인 지원)
3. **무료 시작** — 계정 없이 전 기능 사용 가능, 로그인 시 여러 기기 동기화

## 5. 영상 구성 가이드 (권장 콘티)

> 제작사가 더 나은 구성을 제안하면 우선합니다. 아래는 반드시 포함할 메시지입니다.

1. **후킹 (0~5초)**: "조제관리사 시험, 폰 하나로 끝낸다" — 책 더미 대신 스마트폰 화면
2. **문제 제시 (5~15초)**: 방대한 법령·수치·원료 암기의 어려움, 합격 후엔 또 다른 실무 산
3. **해결 — Pass Loop (15~40초)**: 실제 화면 녹화로 시연
   - 기출 퀴즈 풀이 → 오답 시 교재 해당 부분으로 바로 이동
   - 플래시카드 넘기기, 모의고사 과락 판정, 대시보드 학습 통계
   - 숫자 암기·두음법칙 등 암기 특화 도구
4. **해결 — Practice Loop (40~60초)**: Formula OS 시연
   - 원료 선택 → 배합 계산 → 규정 한도 자동 검증(색상 경고)
   - 조제 기록지·라벨 인쇄, 고객 상담 카드
5. **마무리 (60~75초)**: 홈 화면 설치 장면 + CTA
   - "지금 무료로 시작 — 검색: Passmula" 또는 QR/URL 표시

**반드시 포함할 화면**: 기출 퀴즈, 플래시카드, 모의고사 결과(과락 판정),
대시보드 통계, 배합 계산기, 규정 검증 경고, 조제 기록지 출력물.
제작용 데모 데이터 세팅은 의뢰인이 지원합니다.
