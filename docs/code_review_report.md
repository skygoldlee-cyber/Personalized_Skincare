## 📂 프로젝트 구조 개요

프로젝트는 모던하고 프리미엄한 다크 테마(Dark Theme) 기반의 **단일 페이지 애플리케이션(SPA)** 형태로 개발되었습니다. 별도의 무거운 프레임워크나 외부 라이브러리(Chart.js, lodash 등) 의존성 없이, 순수 웹 표준 기술(Vanilla JS, CSS, HTML5)로만 매우 풍부한 반응형 UX를 구현한 점이 특징입니다.

### 핵심 파일 구성
*   **`index.html`**: SPA 구조의 뼈대와 각 학습 모듈(대시보드, 플래시카드, 퀴즈, 복습노트, 훈련소, 예상문제집, 성분사전)의 뷰 컴포넌트 구조 정의.
*   **`app.js`**: 애플리케이션의 핵심 비즈니스 로직, 라우팅, 오답 복습 필터링, 난수식 계산 문제 생성기, 모의고사 시뮬레이터 로직 포함.
*   **`src/charts.js`**: SVG 성적 추이 차트, 레이더 차트, 합격 진단, 한글 초성 추출 유틸리티 (v1 리뷰의 모듈화 권고가 부분 반영됨).
*   **`src/scratchpad.js`**: HTML5 Canvas 2D 기반 손글씨 계산 연습장 이벤트 핸들러.
*   **`src/state.js`** *(v3 신규)*: 전역 학습 상태 객체(`state`)와 로컬스토리지 영속성 로직(`loadProgress`/`saveProgress`)을 분리한 모듈 (권고 #1의 첫 단계).
*   **`src/sanitize.js`** *(v3 신규)*: XSS 방어용 HTML 이스케이프 유틸리티(`escapeHTML`, `safeTextWithBreaks`, `esc`) (권고 #3 대응).
*   **`style.css`**: 다크모드 전용 컬러 팔레트, 글라스모피즘 스타일링, 그리드 레이아웃, 인쇄 레이아웃(`@media print`) 및 인터랙티브 애니메이션 정의.
*   **데이터 셋 (`*_data.js`)**: 학습용 요약 데이터(`study_data.js`), 성분 백과 데이터(`ingredients_data.js`), 모의고사 데이터(`exam_data.js`)로 구성.

## ✨ 주요 강점 (Core Strengths)

1.  **뛰어난 비주얼 디자인 & 프리미엄 다크 테마**
    *   `style.css`에서 정의된 일관성 있는 디자인 토큰(Luminous Cyan, Neon Violet 등)과 글라스모피즘을 적용하여 기존의 단순한 퀴즈 앱들과 차별화되는 매우 고급스러운 비주얼을 자랑합니다.
    *   아이콘 배치, 호버 효과, 연속 학습 불꽃 애니메이션(`streak-fire-icon`) 등의 마이크로 인터랙션을 통해 학습 몰입도를 크게 개선하였습니다.

2.  **의존성 제로(Zero-dependency) SVG 차트 엔진**
    *   성능 저하 및 번들 크기 증가의 원인이 되는 외부 차트 라이브러리 없이, 순수 JavaScript로 SVG 벡터를 빌드하는 방식(`renderPerformanceChart`, `renderRadarChart`)을 도입했습니다.
    *   반응형 논리 좌표계(ViewBox)를 구현하여 모바일, 태블릿, PC 등 모든 스크린 크기에서 깨짐 없이 완벽하게 렌더링됩니다.

3.  **오프라인 친화적 아키텍처**
    *   학습 상태(외운 카드, 헷갈린 카드, 퀴즈 기록 등)를 브라우저 `localStorage`와 연동하여 인터넷이 없는 환경에서도 학습 진도가 완전히 보존됩니다.
    *   데이터 백업/복원 기능을 탑재하여 브라우저 쿠키 삭제나 기기 변경 상황에서도 진도를 잃지 않도록 보완하였습니다.

4.  **주관식 유사어 채점 엔진**
    *   `checkShortAnswer`에서 한글 조사 제거, 괄호/원문자 마커 제거, 동의어 사전(`SYNONYMS_DICTIONARY`), 멀티파트 정답((A)/(B) 결합형) 분기 처리까지 구현하여 실전 시험 환경의 채점 관용도를 높인 정교한 로직이 돋보입니다.

## 🐛 v2 신규 발견 버그 및 수정 내역 (6건 전부 수정 완료)

### 1. 백업 복원 화이트리스트 키 불일치 (심각도: 높음) — 수정 완료
*   **문제**: `importData()`의 `ALLOWED_KEYS`에 `'streak_days'`와 `'sim_draft'`가 포함되어 있었으나, 실제 앱이 사용하는 키는 `'study_streak'`와 `'sim_draft_session'`입니다. 이로 인해 백업 파일을 복원필 때 **모의고사 임시 세션과 연속 학습일 데이터가 복원되지 않는 버그**가 있었습니다.
*   **수정**: 화이트리스트를 실제 사용 키(`sim_draft_session`, `pomo_total_time_date` 등)로 교정하고, 값이 문자열인지 추가 검증(`typeof data[k] === 'string'`)하여 `localStorage` 오염을 방지했습니다.

### 2. 데이터 백업 시 다수의 학습 데이터 누락 (심각도: 높음) — 수정 완료
*   **문제**: `exportData()`가 7개 정적 키만 백업하여 `sim_draft_session`(모의고사 임시 저장), `calc_history`(계산 풀이 기록), `daily_completed_YYYY-MM-DD`(일일 챌린지 완료 여부)가 백업에서 누락되었습니다. 기기 변경 시 해당 데이터가 유실되었습니다.
*   **수정**: `getBackupKeys()` 헬퍼를 신설하여 정적 키 10개 + `daily_completed_` 접두사의 동적 키를 `localStorage`에서 자동 수집하도록 변경했습니다. `importData`의 화이트리스트도 동일하게 `daily_completed_` 접두사를 허용합니다.

### 3. 모의고사 시험 타이머의 백그라운드 스로틀링 취약점 (심각도: 높음) — 수정 완료
*   **문제**: 뽀모도로 타이머는 v1 권고에 따라 타임스탬프 기반으로 수정되었으나, **정작 100분짜리 모의고사 시험 타이머**는 여전히 `setInterval(1000)` + `timeLeft--` 차감 방식이었습니다. 시험 중 백그라운드 탭 전환 시 브라우저가 타이머를 스로틀링(최대 1분 지연)하여 **실제보다 시간이 느리게 흘러 부정행위로 오인될 수 있는** 치명적 버그였습니다.
*   **수정**: `startSimTimer()`를 신설하여 종료 시각(`endTime = Date.now() + timeLeft*1000`)을 고정하고, `tickSimTimer()`에서 절대 시각 차이로 남은 시간을 계산하도록 변경했습니다. 시간 만료 시 `00:00` 표시도 명시적으로 갱신합니다.

### 4. 뽀모도로 "오늘 누적 집중 시간"이 날짜 변경 후에도 리셋되지 않음 (심각도: 중간) — 수정 완료
*   **문제**: UI에 "오늘 누적 집중 시간"으로 표기되나 `pomo_total_time`은 영구 누적되어 며칠이 지나도 초기화되지 않았습니다.
*   **수정**: `pomo_total_time_date` 키를 신설하여 마지막 누적 날짜를 기록하고, `loadProgress()`에서 날짜가 바뀌었으면 0으로 리셋하도록 변경했습니다.

### 5. "진도 초기화" 버튼이 일부 데이터를 남김 (심각도: 중간) — 수정 완료
*   **문제**: `reset-progress-btn` 핸들러가 `fc_memorized`, `fc_weak`, `quiz_results` 3개만 초기화하고, **모의고사 성적 이력(`sim_results_history`), 연속 학습일(`study_streak`), 계산 기록(`calc_history`), 일일 챌린지 완료 키**를 그대로 두어 초기화 후에도 대시보드 차트와 스트릭이 남아있는 불일치 상태가 발생했습니다.
*   **수정**: 인메모리 상태와 함께 로컬스토리지의 학습 관련 키 전체(정적 10개 + `daily_completed_*` 동적 키)를 제거하도록 확장했습니다.

### 6. 한글 초성 추출 범위 경계값 오류 (심각도: 낮음) — 수정 완료
*   **문제**: `getChosung()`의 완성형 한글 음절 판정 상한이 `11172`로 되어 있었으나, 유효 범위는 `0~11171`(가~힣)입니다. 코드 11172는 존재하지 않는 음절로, 해당 유니코드(0xD7A4 근방 사영역) 입력 시 초성 배열 인덱스를 벗어나 `undefined`가 반환될 수 있었습니다.
*   **수정**: 상한을 `11171`로 교정하고 범위 주석을 추가했습니다.

## ✅ v3 권고 적용 내역 (미적용 3건 전부 적용 완료)

v2의 "향후 개선 권고 사항" 3건을 모두 코드에 반영했습니다. 세부 내역은 다음과 같습니다.

### 1. 거대한 단일 자바스크립트 파일 (Monolithic File) — ✅ 점진적 모듈화 착수
*   **조치**: 권고안의 첫 단계로, 전역 상태 객체(`state`)와 그 영속성 로직(`loadProgress`/`saveProgress`)을 [`src/state.js`](src/state.js)로 분리했습니다. `app.js`는 3,300+ → **3,200+ 라인**으로 축소되었고, 상태 레이어가 독립 모듈로 명확히 경계 지어졌습니다.
*   **설계 노트**: `index.html` 전반에 인라인 `onclick="fnName()"` 핸들러가 전역 함수 스코프에 의존하므로, 안전성을 위해 이번 단계는 전역 스코프를 유지한 채 논리적 모듈로 분리하는 방식을 택했습니다. `src/state.js`는 부수효과 없는 순수 선언으로 작성되어 있어, 향후 ES Modules(`<script type="module">`) 전환 시 `export`/`import` 추가만으로 마이그레이션 가능합니다.
*   **후속 과제(선택)**: `src/trainer.js`(수치/계산/원료 훈련), `src/simulator.js`(모의고사/OMR), `src/daily.js`(데일리 챌린지/스트릭) 분리는 동일한 패턴으로 점진 적용 가능합니다.

### 2. 초기 로드 시 대용량 데이터 동기 탑재 — ✅ `defer` 지연 로딩 적용
*   **조치**: [`index.html`](index.html)의 `study_data.js`, `ingredients_data.js`, `exam_data.js` 및 `src/charts.js`, `src/scratchpad.js`, `src/state.js`, `app.js` 전체에 `defer` 속성을 부여했습니다. 이로써 HTML 파싱이 데이터 다운로드로 블로킹되지 않으며, 스크립트는 문서 파싱 완료 후 삽입 순서대로 실행되어 기존 의존 순서(데이터 → 모듈 → app)가 그대로 보장됩니다.
*   **효과**: 초기 페인트(First Paint) 차단이 해소되어 체감 로딩 속도가 개선됩니다.

### 3. XSS 잠재 경로 — `innerHTML` 직접 주입 — ✅ 이스케이프 헬퍼 도입 및 전면 적용
*   **조치**: [`src/sanitize.js`](src/sanitize.js)를 신설하여 `escapeHTML()` / `safeTextWithBreaks()` / `esc()` 헬퍼를 제공하고, 데이터 주입이 발생하는 **`innerHTML` 경로 전반(약 30곳)**에 적용했습니다.
    *   `safeTextWithBreaks()`: 데이터 이스케이프 후 개행만 `<br>`로 변환 — 플래시카드 본문, 퀴즈/모의고사 문제, 복습 카드, 데일리 챌린지, 계산 기록 등에 적용.
    *   `esc()`: 템플릿 리터럴 내 데이터 조각 이스케이프 — 대시보드 과목명, 성분 사전 카드, OMR/한도/원료 옵션, 모의고사 해설, 성적 분석 블록 등에 적용.
    *   앱 내부에서 생성하는 의도적 마크업(`<strong>`, `<br>`)은 유지하되, 그 안에 삽입되는 원료명·과목명·사용자 입력값 등 **비신뢰 데이터 조각만 선택적으로 이스케이프**하도록 소스 생성부에서 처리했습니다.
*   **효과**: 향후 외부/비신뢰 데이터가 유입되더라도 스크립트·마크업 인젝션이 구조적으로 차단됩니다.

## 📈 총평

본 프로젝트는 **고성능 다크 모드 인터페이스, 반응형 글라스모피즘 설계, 라이브러리 프리 SVG 렌더링**을 완벽하게 조합하여 수려한 학습 환경을 제공하고 있습니다.

v2에서 발견된 **6건의 실제 버그**가 모두 수정되었고, v3에서는 잔여 권고 3건인 **코드 모듈성(상태 레이어 분리), 대용량 데이터 `defer` 지연 로딩, `innerHTML` 인젝션 경로 정리(XSS 헬퍼 전면 적용)**까지 모두 반영되어 **보고서 내 모든 개선 권고가 해소**되었습니다.

후속 선택 과제로 `trainer`/`simulator`/`daily` 도메인의 추가 모듈 분리와 ES Modules 전환이 남아 있으나, 현재 상태만으로도 안전성·성능·유지보수성이 크게 강화된 프리미엄 학습 솔루션입니다.
