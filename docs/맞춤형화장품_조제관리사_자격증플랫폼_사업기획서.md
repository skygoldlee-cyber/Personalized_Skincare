## 0. 문서의 목적과 독자

본 문서는 **맞춤형화장품 조제관리사 자격증 시험 대비 스마트 학습 플랫폼**의 사업 타당성, 제품 정의, 수익 모델, 개발 로드맵을 정리한다.

**현재 프로젝트는 이미 MVP를 넘어선 학습 플랫폼으로 운영 중**이며, 4과목 교재·1000문항 문제은행·1357개 성분 DB·PWA 오프라인 학습 등 핵심 기능이 구현 완료된 상태다. 본 문서는 구현된 자산을 기반으로 **수익화 전환과 기능 확장**을 위한 사업 계획을 정리한다.

> ⚠️ **면책** — 본 문서의 법령·자격제도 서술은 사업 방향 설정을 위한 정리이며 법률 자문이 아니다. 실제 사업화 전 관련 법령 및 자격제도 운영기관의 최신 기준을 확인한다.

## 1. 사업 개요

### 1.1 서비스명

- **현재 명칭:** Cosmetic Pass Master (코스메틱 패스 마스터)
- 배포 URL: https://personalized-skincare-study.vercel.app
- 패키지명: `cosmetic-pass-master` (package.json)

### 1.2 한 문장 정의

> **"맞춤형화장품 조제관리사 자격증 시험에 필요한 법령·성분·조제 실무 지식을 오프라인 PWA 학습 플랫폼으로 언제 어디서나 학습할 수 있게 돕는 모바일·웹 서비스."**

### 1.3 배경 — 왜 이 사업인가

```text
화장품법 개정 (맞춤형화장품 제도 도입)
    ↓
맞춤형화장품 판매업소 신고제 + 조제관리사 자격 요건
    ↓
자격증 수요 급증 (신규 진입자, 기존 뷰티 종사자, 창업 준비자)
    ↓
기존 학습 수단: 단행본·인강·오프라인 학원 ← 비효율적, 비싸다, 갱신 어렵다
    ↓
AI 기반 개인화 학습 플랫폼 = 시장 공백
```

### 1.4 현재 구현 상태 요약

본 프로젝트는 **이미 핵심 학습 기능이 구현 완료된 상태**로, 별도의 MVP 개발 없이 즉시 사용자 확보가 가능하다.

## 2. 시장 분석

### 2.1 맞춤형화장품 조제관리사 제도 개요

| 항목 | 내용 |
|---|---|
| 근거 법령 | 화장품법 제3조의2, 시행규칙 제8조의2 등 |
| 자격 성격 | 맞춤형화장품 판매업소에서 조제(혼합·소분)를 수행하기 위해 필요한 자격 |
| 시험 주체 | **대한상공회의소 자격평가사업단** (2024년 하반기 이관, license.korcham.net) |
| 시험 과목 | **4과목** (화장품법의 이해, 화장품 제조 및 품질관리, 유통화장품 안전관리, 맞춤형화장품의 이해) |
| 문항 수 | 과목1 100제, 과목2 250제, 과목3 250제, 과목4 400제 (총 1,000제) |
| 응시 대상 | 화장품 브랜드 직원, 뷰티숍 종사자, 창업 준비자, 프리랜서 뷰티 전문가 |

### 2.2 시장 규모 추정

| 지표 | 추정 | 근거 |
|---|---|---|
| 연간 응시자 수 | 수천~수만 명 | 맞춤형화장품 판매업소 증가 추세 + 신규 진입자 |
| 1인 학습 지출 | 5~30만원 (인강·학원·교재) | 기존 자격증 시장 평균 |
| 시장 규모(연) | 50~200억원 추정 | 응시자 × 1인 지출 (보수적 추정) |
| 경쟁 플랫폼 | **거의 없음** | 기존은 단행본·인강 중심, AI 플랫폼 = 공백 |

### 2.3 경쟁 지형

| 사업자 | 형태 | 한계 |
|---|---|---|
| 기출문제집 (출판사) | 단행본 | 법령 개정 시 즉시 구식, 개인화 불가 |
| 인강 (오프라인 학원) | 강의 | 비싸다(30만원+), 시간·장소 제약, 업데이트 느림 |
| 일반 자격증 앱 (해커스 등) | 모바일 퀴즈 | 화장품 전문 성분·조제 실무 미대응 |
| **본 플랫폼** | **PWA 오프라인 + 1000문항 + 성분 DB + 법령 자동 업데이트** | — |

> **차별화:** 화장품 성분·법령 전용 Knowledge Base (자체 구축 1357개 성분 + 법령원문 36종) + 오프라인 PWA + 이야기형 교재 (스토리텔링 기반 학습) + Mermaid 시각화 다이어그램.

## 4. 법적 경계 및 컴플라이언스

### 4.1 자격증 시험과 본 서비스의 관계

- 본 플랫폼은 **학습 보조 서비스**이며, 자격증 시험 주체(대한상공회의소 자격평가사업단)와 무관하다.
- "합격 보장" 표현 금지 → "학습 효율 향상", "약점 분석"으로 표현.
- 기출문제는 **시험 주체의 공식 출처**를 확인하여 저작권·사용 기준을 준수한다.
- 현재 문제은행은 **교재 인용 문제**로 자체 제작되었으며, 공식 기출문제가 아니다.

### 4.2 콘텐츠 저작권

| 콘텐츠 | 출처 | 저작권 처리 |
|---|---|---|
| 법령 조문 | 공공데이터(법령정보센터) | 공공저작물 자유이용 가능 |
| 성분 정보 | 식약처 공공데이터 + 자체 정제 | 출처 표기, 가공 콘텐츠 자체 저작권 |
| 교재 본문 | 자체 제작 (표준형 + 이야기형) | 자체 저작권 |
| 문제은행 | 교재 인용 자체 제작 (1000문항) | 자체 저작권 |
| 참조자료 | 법령원문 8종 + 고시·별표 36종 | 공공데이터 기반, 출처 표기 |
| 오디오북 | TTS 기반 자체 생성 | 자체 저작권 (음성) |
| 강의 콘텐츠 | 자체 제작 / 전문가 위탁 (향후) | 계약에 따라 독점·비독점 설정 |

### 4.3 개인정보 보호

- **현재 상태**: 계정 시스템 없음, 모든 학습 데이터는 `localStorage`에만 저장 (서버 전송 없음)
- **수익화 전환 시**: 학습 데이터 동기화를 위해 사용자 데이터 서버 저장 필요 → 최소 수집, 동의, 암호화
- 얼굴 사진 수집 없음 → 개인정보 리스크 최소
- **구독 전환 시 주의**: Supabase/Stripe 해외 서버 사용 시 국외 이전 별도 동의 필요 (SUBSCRIPTION_ROADMAP.md §11 참고)

## 5. 핵심 자산과 기술 구조

### 5.1 자체 구축 자산 (4가지)

1. **시험 Knowledge Base** — 4과목 교재 (표준형+이야기형 8개 MD), 1000문항 문제은행, 법령원문 8종 + 참조자료 36종
2. **성분 DB** — 1,357개 화장품 성분 (배합한도·고시 기준 포함, 빌드 타임 JS 번들)
3. **학습 플랫폼 인프라** — PWA, Service Worker 오프라인 캐시, 모듈러 빌드 파이프라인, 250 단위 테스트 + CI
4. **콘텐츠 제작 파이프라인** — 표준형/이야기형 교재 작성, TTS 오디오북 생성, Mermaid 다이어그램 + 매핑 표

### 5.2 현재 아키텍처

```text
        공공데이터 (법령/고시/성분)  ←  수동 수집·정제
                 │
          Data Pipeline (빌드 타임 MD→JS 번들, 출처·기준일 태깅)
                 │
        시험 Knowledge Base (정적 JS 번들)
          ├─ 법령 과목 (100문항)
          ├─ 제조·품질과목 (250문항)
          ├─ 안전관리 과목 (250문항)
          └─ 맞춤형화장품 과목 (400문항)
                 │
     ┌───────────┼───────────┐
   콘텐츠 학습   플래시카드   모의고사 엔진
   (교재 리더)   (암기 카드)  (시뮬레이터)
     └───────────┼───────────┘
                 ▼
        학습자 대시보드 (PWA, 오프라인)
                 │
        localStorage (학습 진도·오답·북마크)
```

### 5.3 기술 스택 (실제 구현 기준)

## 7. 검증 계획과 로드맵

> 원칙: **결제 전환 → 개인화 고도화 → B2B 확장** 순.
> 현재 무료 플랫폼이 이미 운영 중이므로 Step 0(수요 검증)은 불필요.

| 단계 | 목표 | 예상 소요 | 핵심 KPI (Go/No-Go) | 산출물 |
|---|---|---|---|---|
| **Step 1** | 구독 전환 인프라 | 7~12주 | 첫 유료 전환 ≥ 1건, 구독 가입률 ≥ 5% | Supabase Auth, 결제(Stripe/토스), 콘텐츠 게이팅, 데이터 동기화 |
| **Step 2** | 개인화 학습 | 4~8주 | 진단 완료율 ≥ 60%, 재방문율 ≥ 30% | 진단 평가, 약점 프로파일, 간격 반복 (SM-2) |
| **Step 3** | 합격 사례 창출 | 8~12주 | 합격자 배출 1명 이상, NPS ≥ 40 | 합격 예측 모델, 오답 패턴 분석, 멘토링 |
| **Step 4** | B2B 확장 | 12~16주 | 학원·브랜드 B2B 계약 1건 이상 | 학원용 대시보드, 단체 라이선스 |
| **Step 5** | 생태계 확장 | 지속 | MAU ≥ 1,000, 유료 전환율 ≥ 10% | 커뮤니티, API, 크리에이터 콘텐츠 |

> ⚠️ 각 Step은 이전 Step의 Go/No-Go 기준 충족 시에만 진행.
> Step 1 예상 기간은 SUBSCRIPTION_ROADMAP.md의 상세 분석(§13) 기준: CSP 재설계, SW 재작업, 결제 웹훅 등 포함.

## 13. 데이터베이스 설계 (구독 전환 시 — SUBSCRIPTION_ROADMAP.md 기반)

> **현재 상태**: 서버 DB 없음. 모든 데이터는 localStorage에 저장.
> 구독 전환 시 Supabase (PostgreSQL) 도입 예정.

```text
users (id, email, name, created_at, role)
subscriptions (user_id, plan, status, current_period_end, stripe_subscription_id)
study_progress (user_id, subject_key, card_id, status, quiz_results, updated_at)
payments (user_id, amount, currency, stripe_payment_id, status, created_at)
```

> `card_id`는 콘텐츠 유도형 stable ID (sha256)로 기기·재빌드 간 안정적.
> 기존 `state.js`의 `saveProgress` 추상화 seam을 API 호출로 교체하여 동기화 구현.
> `ALLOWED_KEYS` 화이트리스트를 서버 업서드 검증에 재사용 가능.

```text
User ──▶ Subscription ──▶ StudyProgress (card_id = stable sha256)
  │
  └──▶ localStorage (saveProgress seam) ──▶ Supabase (Pro만 동기화)
         │
         └── 병합: Set=합집합(union), 스칼라=LWW
```

## 15. 요약 — 핵심 전략 3가지

1. **이미 구현된 학습 플랫폼 위에 결제를 얹는 최소 전환** — 4과목 교재·1000문항·1357성분 DB·PWA 오프라인 등 핵심 기능 완성. MVP 개발 없이 즉시 수익화 가능.
2. **구독 전환을 최우선으로** — 현재 무료 사용자 기반이 존재하므로, 수요 검증 없이 결제 전환(Step 1)부터 시작. SUBSCRIPTION_ROADMAP.md 기준 7~12주 소요.
3. **자격증 학습 → B2B 교육 → 화장품 전문가 생태계로 확장** — 단기는 B2C 합격 학습, 중기는 B2B 기업·학원 교육, 장기는 화장품 전문 플랫폼.

> **비전 문장:** "맞춤형화장품 조제관리사 자격증을 오프라인 PWA와 개인화 학습으로 가장 효율적으로 준비할 수 있는 플랫폼, 나아가 화장품 전문가 생태계의 교육 허브."
