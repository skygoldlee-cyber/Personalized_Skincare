# 판매업소 Step 0 인터뷰 스크립트

> 근거 문서: `FORMULA_OS_경쟁전략.md` (§0 선택지·중단 기준, §1 경쟁 지도, §2-A, §4.1)
> 목적: Formula OS 유료화 여부를 **코드 작성 전에** 판단한다. 인터뷰는 기능 소개가 아니라 **현재 업무 관찰**이 목적.

---

## 0. 판단 기준 (인터뷰 시작 전 확정 — 확증 편향 방지)

| 항목 | 기준 |
|---|---|
| 표본 | **독립 판매업소 최소 10곳** (가맹점은 분모에서 제외 — 개별 구매자가 아님) |
| 유료화 진행 | 월 2만원 이상 지불 의사 **30% 이상** (3곳 이상) |
| 무료 전환 | 30% 미만 → 유료화 포기, 무료 부가 기능으로 유지 (§0 선택지 C) |
| A/B 분기 | 지불 의사 낮지만 사용 의향 높음 → A(Pro 부가 가치) / 교육기관 도입 의향 확인 → B(B2B 라이선스) |
| 보조 기준 | 말보다 행동 — 사전 예약·유료 파일럿 신청·연락처 대기 명단 등록을 행동 신호로 |

## 1. 대상 선정 질문 (인터뷰 성립 확인 — 3분)

1. **혹시 프랜차이즈·브랜드 가맹점이신가요, 독립 업소이신가요?**
   - 가맹점 → 별도 집계 (본사 시스템 존재 여부는 §2 질문으로 정보 수집 후 종료)
   - 독립 → 인터뷰 계속, 분모에 포함
2. **맞춤형화장품 조제·판매를 실제로 하고 계신가요?** (신고만 한 곳 제외 — 225개사의 활성 비율 추정 근거)

## 2. 현재 업무 방식 (대체재 파악 — 10분)

3. **조제하면서 기록하는 걸 지금 뭘로 하세요?** (수기·엑셀·POS·본사 시스템·협회 무료 양식·기타)
   - 각 답변 → §1 경쟁 지도의 실제 점유율이 됨
   - POS 답변 시: **"POS에 판매내역서 항목(제조번호·사용기한·판매량)이 다 남나요?"** — POS가 법정 항목을 갖추는지 확인
4. **가맹점이라면: 본사에서 기록 도구나 서식을 내려주나요?** — §1.2 "프랜차이즈 본사 시스템 존재 여부 미확인" 해소
5. **기록한 건 어디에 보관하고, 백업은 어떻게 하세요?** — §2-A 백업 수요 확인
6. **법령이 바뀌면 어떻게 아세요? 원료 사용 한도는 뭘로 확인하세요?** — 고시 추적 방식 = 축 1 가치 검증

## 3. 법정 의무 인식 (기능 기회 확인 — 10분)

7. **판매내역서는 작성해서 보관하고 계세요?** (시행규칙 제12조의2 제3호) — 양식을 아는지, 보관 기간을 아는지
8. **매년 2월 말 원료 목록 보고(협회 경유)는 하세요? 어떻게 작성하세요?** — 협회 엑셀 서식보내기 기능의 가치 확인
9. **반기 안전성 정보 보고(1월·7월) 알고 계세요?** — 리마인드 기능 수요
10. **부작용 생기면 "누구에게 팔았는지" 추적해야 하나요? 지금 그게 가능한가요?** — §2-A 고객-판매 연결표 설계 필요 여부

## 4. 지불 의사 (중단 기준 핵심 — 5분)

11. **이런 기록이 자동으로 되는 도구가 있다면 월 얼마까지 낼 수 있으세요?**
    - ⚠️ 답변은 실제 지불보다 후하게 나옴 — 행동 신호와 함께 평가
12. **지금 이 자리에서 유료 파일럿(월 ○○원, 환불 보장)에 신청하실 수 있으세요?** — 행동 신호
13. **출시되면 연락드려도 될까요? (연락처·대기 명단)** — 행동 신호
14. (교육기관 관련자라면) **실습용 도구로 도입 의향이 있으세요?** — B 분기 근거

## 5. 마무리 (2분)

15. **이 도구에 꼭 있어야 할 것, 있으면 오히려 안 쓸 것은?**
16. **같은 업 하시는 분 중 소개해주실 수 있는 분이 있을까요?** — 표본 확보 경로

## 6. 응답 집계 시트 (인터뷰마다 기입)

| 항목 | 기록 |
|---|---|
| 업소 유형 | 독립 / 가맹(본사: ___) / 미영업 신고 |
| 현재 기록 도구 | 수기 / 엑셀 / POS / 본사 시스템 / 무료 양식 / 기타 |
| 판매내역서 작성 여부 | 예 / 아니오 / 모름 |
| 원료 목록 보고 방식 | 협회 서식 수기 / 안 함 / 모름 |
| 백업 방식 | 없음 / 수동 / 클라우드 |
| 지불 의사 | 월 ____원 / 없음 / 모르겠음 |
| 행동 신호 | 파일럿 신청 ☐ / 연락처 제공 ☐ / 없음 ☐ |
| 기타 메모 | |

> 집계는 §0 기준표와 대조 — 독립 업소 10곳 달성 시 중단/진행 판단.
