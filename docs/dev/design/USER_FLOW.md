# 사용자 흐름 명세 (User Flow)

> **목적**: 화면 간 전환·상태 분기를 개발자와 AI 코딩 도구가 오해 없이 구현할 수 있도록, 핵심 사용자 여정을 흐름도 + 진입/종료 조건으로 정의한다. 화면 단위 요구사항은 [SPEC.md](../SPEC.md) §3.x, 화면 인벤토리는 [SCREEN_MAP.md](../reference/SCREEN_MAP.md) 참조 — 본 문서는 **"흐름"의 계약**이다.
> **작성 규칙**: 각 흐름은 ① 진입 조건 ② 분기 다이어그램 ③ 종료/전이 조건 ④ 상태 저장 지점(localStorage 키) 순으로 기술. 새 화면 간 전환을 추가할 때는 해당 흐름을 먼저 갱신한다.
> **최종 업데이트**: 2026-10-02
> **문서 ID**: DOC-DSN-11
> **관련 SPEC ID**: `UX-NAV-06~08`(팔레트·스크롤·해시 라우팅) · `UX-FB-05`(온보딩) · `UM-01~05`(모드 전환) · `TR-01~23`(리더) · `FO-01~23`(Formula OS) · `AU-01~08`(계정·동기화 §3.19)

## 1. 앱 기동 — 첫 방문 vs 재방문

```
앱 로드 (index.html)
  ↓
bootstrap: exams.json 로드 → 활성 시험 해석 (scoped localStorage)
  ↓
ui_mode 확인 ──────────────┐
  │                        │
study 모드              practice 모드
  ↓                        ↓
dashboard-view 랜딩     formula-view 랜딩 (feature:formula 있을 때)
  ↓                        │
첫 방문?                   │
  ├─ 학습키 없음 → 시작 안내 모달 (onboarding_seen_v1, 1회)
  └─ 학습키 있음(기존 사용자) → 조용히 통과
```

| 항목 | 규약 |
|------|------|
| 초기 뷰 | 해시(`#/slug`) 딥링크 우선 → 없으면 모드별 랜딩 (UX-NAV-08) |
| 첫 방문 판정 | `quiz_results`/`fc_memorized`/`study_streak`/`sim_results_history` 중 하나라도 존재 → 재방문 (`src/onboarding.js`) |
| 온보딩 | 3단계 안내(문제집·모의고사·복습 루프) — 확인/ESC/백드롭 닫기, 설정 메뉴로 재열람 가능 |

## 2. 핵심 학습 루프

```
대시보드
  ├─ 과목 카드 → 문제집 열람 (exam-viewer 오버레이 — 뷰 전환 아님)
  ├─ 이어보기 → textbook-reader-view (저장 위치로 복원)
  ├─ 학습 시작 → flashcard-view / quiz-view / trainer-view
  └─ 오늘 복습 → review-view
            ↓
   학습 활동 수행 (카드 암기 / 퀴즈 풀이 / 드릴)
            ↓
   결과 기록 (quiz_results · fc_memorized · statement 오판 통계)
            ↓
   오답 발생? ──┬── 없음 → 다음 문제 / 진도 갱신
               ↓ 있음
        복습노트 + SM-2 간격 반복 자동 등록
               ↓
   review-view 집중 복습 / trainer 취약 드릴 ──→ 재채점 → 졸업
```

| 저장 지점 | 키 | 내용 |
|----------|-----|------|
| 퀴즈 결과 | `quiz_results` | 점수·오답 → 리뷰 목록 원천 |
| 카드 암기 | `fc_memorized` | 완료 배지·진도 |
| 오판 통계 | statement-tracker | 진술 원자(sid) 단위 — SM-2 졸업 판정 |
| 학습 활동 | `study_streak` 등 | 캘린더·스트릭 표시 |

**계약**: 모든 학습 완료 경로는 진도를 `localStorage`에 즉시 저장하고(오프라인 우선), 로그인 사용자는 클라우드 동기화로 이어진다(§3.19). "오답 → 복습 등록"은 자동이며 사용자 액션을 요구하지 않는다.

## 3. 교재 읽기 흐름

```
textbook-reader-view 진입
  ↓
과목 선택 셀렉트 (미선택 시 empty-state 안내)
  ↓
챕터 로드 → TOC 사이드바 + 본문 카드 렌더
  ↓
├─ 이야기형 토글 → 스토리 번들로 재렌더 (읽기 위치 보존, TR-19)
├─ 스크롤 읽기 → 스크롤 스파이 + 진행바 + 섹션 표시줄
│     ├─ 스크롤 다운 → 크롬 자동 숨김 (TR-22/23)
│     └─ 스크롤 업 → 크롬 복귀
├─ TOC 클릭 → 해당 섹션으로 스크롤 (scroll-margin은 크롬 높이 실측 연동)
├─ 모바일 TOC → 왼쪽 엣지 스와이프/목차 버튼 → 드로어
├─ 검색/글자크기/집중모드 → 툴바 패널 (오버레이)
└─ 오디오 토글(이야기형, PRO) → 재생 패널
  ↓
읽기 위치 자동 저장 (스크롤 디바운스) → 다음 방문 이어보기
```

| 항목 | 규약 |
|------|------|
| 모드 전환 | 표준형↔이야기형 전환 시 현재 섹션 앵커+오프셋 복원 (TR-19) |
| 뷰 이탈 | 다른 뷰 이동 시 집중 모드 해제 + 오디오 정지 (`navigateToView`) |
| 레이아웃 불변식 | 뷰가 `.main-content` 잔여 높이를 정확히 채움 — 페이지 스크롤 범위 존재 금지 (TR-23) |

## 4. 모의고사 흐름

```
exam-view → 과목 선택 → 유형 선택 (실전 선다+단답 / ㄱㄴㄷ 조합 · 20/40/전체)
  ↓
응시 — OMR 마킹 + 타이머
  ↓
제출 → 채점 → 과락 판정(과목별 40% 미만)
  ↓
결과 화면 → 오답 리뷰(해설) → 오답은 복습·통계 자동 등록 → 학습 루프로 귀환
```

## 5. Formula OS 실무 흐름

```
고객 등록 ──┐
원료 장부 ──┤   (입고·기한·재고)
           ↓
     처방(formula) 작성 — 베이스 선택 → 원료·비율 배합
           ↓
     규정 검증 — 고시 한도·상호작용·안정성 판정 (4상태)
           ↓
     My 포뮬러 저장 (한도 5개) ←→ 수정·복제
           ↓
     배치(batch) — 조제 회차: 일자·량·고객·QC 5항목·위생 체크
           ↓
     산출물 — 조제 기록지 / 제품 라벨(70mm) / 사용 안내문 인쇄
```

상세 엔티티·생명주기는 [FORMULA_OS_WORKFLOW_DESIGN.md](FORMULA_OS_WORKFLOW_DESIGN.md) (DOC-DSN-02) 참조.

## 6. 시험 전환 흐름

```
설정 패널 / 더보기 시트 → '시험 전환' (등록 시험 ≥2개일 때만 표시)
  ↓
exam-select-view — 카드 목록 (현재 시험 배지 / 준비중 배지)
  ├─ 현재 시험 → 대시보드 복귀
  ├─ comingSoon 시험 → '준비 중' 알림, 전환 없음
  └─ 다른 시험 → selectExam → 페이지 리로드 → 해당 시험 컨텍스트로 재기동
```

**계약**: 진도·설정은 시험별 scoped localStorage로 독립 (`scopedKey`) — 시험 간 데이터 오염 없음. `ui_mode` 등 기기 설정은 시험과 무관하게 전역.

## 7. UI 모드 전환 (학습 ↔ 실무)

```
토글 (사이드바 푸터 / 설정 패널)
  ↓
ui_mode = 'practice' → 학습 전용 nav 숨김
  ├─ 현재 뷰가 학습 전용이면 → formula-view로 자동 랜딩
  └─ 학습 도구는 '학습 도구 펼치기' 토글로 임시 접근 가능 (ui_study_tools_open)
ui_mode = 'study' → 전체 nav 복원
```

## 8. 계정·클라우드 동기화 (선택)

```
설정 → 로그인 (Supabase 매직링크/OTP — 미설정 시 해당 메뉴 없음)
  ├─ 성공 → 클라우드 동기화 활성 (로컬 진도 ↔ 원격 병합)
  └─ 미로그인/실패 → localStorage 단독 동작 — 모든 기능 정상
```

**계약**: 로그인은 선택 사항이며 기능 게이팅을 하지 않는다(§3.19). 오프라인 상태에서는 로컬 저장이 항상 1차다(§4.1~4.2).

## 9. 공통 상태 규약 (모든 흐름에 적용)

| 상태 | 규약 | 근거 |
|------|------|------|
| 로딩 | `showGlobalLoading()` 전체 오버레이 — 부분 스켈레톤 금지 | UX-FB-04 |
| 빈 상태 | `.empty-state` 패턴 (3rem 아이콘 + 안내 문구 + 다음 행동 유도) | SPEC §4.9.5 |
| 오류 | `showToast(msg,'error')` — 네이티브 alert/confirm 금지 | UX-FB-02 |
| 오프라인 | 전 기능 동작 — 실시간 조회(식약처 고시 등)만 배지로 표시 | §4.1~4.2 |
| 뷰 전환 | 스크롤 복원 / 액션 딥링크는 맨 위 (UX-NAV-07), 해시 동기화 (UX-NAV-08) | — |
