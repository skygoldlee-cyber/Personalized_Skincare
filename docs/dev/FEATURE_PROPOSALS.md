## 1. 기능 분류 기준

각 기능은 다음 기준으로 분류됩니다:

| 분류 | 설명 |
|------|------|
| **학습 효율** | 학습 성과 직접 향상 |
| **콘텐츠 확장** | 새 학습 자료/유형 추가 |
| **사용자 경험** | UI/UX 개선 |
| **구독 가치** | Pro 플랜 차별화 |
| **데이터 분석** | 학습 데이터 인사이트 |
| **접근성** | 장애인/다양한 환경 지원 |
| **기술 인프라** | 성능, 안정성, 유지보수성 |

구현 시점:

| 시점 | 의미 |
|------|------|
| **A** | 현재 Zero-Backend에서 즉시 구현 가능 |
| **B** | Zero-Backend 가능하나 공수 큼 |
| **C** | 구독 전환(Supabase) 후 구현 |

## 2. 학습 효율 향상

### 2.1 AI 맞춤 학습 경로 추천

| 항목 | 내용 |
|------|------|
| **기능** | 사용자의 학습 데이터(암기율, 오답 패턴, 모의고사 성적, 학습 시간)를 분석하여 최적의 다음 학습 단계를 추천 |
| **추천 형태** | "오늘 추천: 2과목 3챕터 카드 학습 → 1과목 오답 퀴즈 10문 → 4과목 계산 연습 5문" |
| **근거** | SM-2 복습 대기 카드 + 정답률 최저 과목 + 헷갈린 카드 최다 과목 + 미학습 챕터 교차 분석 |
| **시점** | A (현재 데이터로 가능, `spaced-repetition.js` + `dashboard.js` 데이터 활용) |
| **Pro 여부** | 무료: 기본 추천 / Pro: 상세 맞춤 경로 |

**구현 방향**:

```
[대시보드 진입]
    │
    ▼
[학습 데이터 분석]
    ├── SM-2 복습 대기 카드 수 (과목별)
    ├── 정답률 최저 과목 (3문 이상)
    ├── 헷갈린 카드 최다 과목
    ├── 미학습 챕터 (암기율 0%)
    └── 최근 모의고사 과락 과목
    │
    ▼
[우선순위 계산]
    1순위: 오늘 복습 대기 카드 (망각 직전)
    2순위: 과락 과목 보완
    3순위: 정답률 최저 과목
    4순위: 미학습 챕터
    │
    ▼
[추천 카드 렌더링]
    "오늘의 추천 학습 경로"
    1. 🔄 2과목 복습 카드 12장 (SM-2 대기)
    2. ⚠️ 1과목 과락 보완 퀴즈 10문
    3. 📖 4과목 3챕터 교재 읽기 (미학습)
```
