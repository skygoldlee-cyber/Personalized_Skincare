앱 설치하기

사용 중인 브라우저에서 아래 순서로 설치하세요.

  1. 1 브라우저의 메뉴 버튼(⋮ 또는 ≡)을 누르세요. (보통 주소창 오른쪽 또는 화면 하단에 있습니다)
  2. 2 메뉴에서 "앱 설치" 또는 "홈 화면에 추가"를 선택하세요.
  3. 3 확인 팝업에서 "설치"를 누륮면 홈 화면에 추가됩니다.

브라우저별 메뉴 위치:
· Chrome: 주소창 오른쪽 ⋮
· Samsung Internet: 화면 하단 ≡ → "페이지를 홈 화면에 추가"
· Whale/기타: 주소창 주변 메뉴 버튼
주소창에 아이콘이 보이면 바로 눌러도 됩니다.

Safari에서 아래 순서로 설치하세요.

  1. 1 화면 하단의 공유 버튼을 누르세요.
  2. 2 메뉴를 아래로 스크롤해 "홈 화면에 추가"를 선택하세요.
  3. 3 오른쪽 상단의 "추가"를 누륮면 완료됩니다.

iOS는 Safari에서만 홈 화면 추가가 가능합니다.

브라우저 메뉴에서 설치 옵션을 찾아주세요.

Chrome: 메뉴(⋮) → "앱 설치" / Safari(Mac): 파일 → "홈 화면에 추가"

현재 인앱 브라우저에서 열려 있습니다

카카오톡·Instagram·Facebook 등 인앱 브라우저에서는 앱 설치가 지원되지 않습니다. Chrome 브라우저에서 열어주세요.

  1. 1 현재 화면 우측 상단 메뉴(⋮ 또는 ≡)를 누르세요.
  2. 2 "다른 브라우저로 열기" 또는 "Chrome으로 열기"를 선택하세요.
  3. 3 Chrome에서 다시 이 페이지를 열고, 주소창 옆 설치 아이콘 또는 메뉴(⋮) → "앱 설치"를 누르세요.
